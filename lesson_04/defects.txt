Дефект №1
Метод capitalize() при вводе строки из букв в верхнем регистре понижает регистр остальных букв после заглавной

Шаги:
1. Передать в метод capitalize() строку в верхнем регистре. Например: tABLE
2. Вызвать метод
3. Проверить возвращаемое значение

Ожидаемый результат: Метод возвращает TABLE
Фактический результат: Метод возвращает Table (принудительно понижает регистр всех последующих букв после заглавной)
Приоритет: Средний
Серьёзность: S3 Major


Дефект №2
Метод contains() при передаче с пустым значеним символа возвращает True вместо False

Шаги:
1. Вызвать метод contains()
2. Передать в строке (string) любое значение. Например: "Love"
3. Передать в строке с искомым символом (symbol) пустое значение
4. Вызвать метод
5. Проверить возвращаемое значение

Ожидаемый результат: Метод возвращает False
Фактический результат: Метод возвращает True
Приоритет: Средний
Серьёзность: S3 Major
