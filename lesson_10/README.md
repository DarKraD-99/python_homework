# Описание базового синтаксиса записи и форматирования

## Проект использует следующие технологии и синтаксис:
1. Python: основной язык программирования для написания тестов.
2. Selenium: Библиотека для автоматизации взаимодействия с веб-браузером.
3. Pytest: Фреймворк для написания и запуска тестов.
4. Allure: Инструмент для генерации отчётов о выполнении тестов.

## Форматирование кода
- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Для документирования методов и функций используются docstrings.
- Все шаги теста размечены с помощью @allure.step или with allure.step(...) для улучшения читаемости отчётов.

## Инструкцию по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите тесты с генерацией отчёта Allure:

```bash
pytest --alluredir allure-results
```

Команда запустит все тесты и сохранит результаты в директорию allure-results.

## Инструкцию по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы посмотреть отчёт, выполните команду:

```bash
allure serve allure-results
```

Команда сформирует отчёт, запустит локальный сервер и откроет отчёт в браузере.

2. В отчёте Allure отображаются:
- Названия тестов: Например, "Тестирование калькулятора" и "Тестирование магазина".
- Описание теста: информация о том, что проверяет каждый тест.
- Шаги теста калькулятора:
    - Открытие страницы калькулятора.
    - Установка задержки в секундах.
    - Нажатие кнопок.
    - Ожидание результата.
    - Проверка результата.
- Шаги теста магазина:
    - Открытие страницы авторизации.
    - Ввод логина и пароля.
    - Авторизация.
    - Добавление товаров в корзину.
    - Ввод личных данных.
    - Проверка общей стоимости купленных товаров.
- Результат: Успешное выполнение тестов или информация об ошибках с указанием ожидаемого и фактического результата.
